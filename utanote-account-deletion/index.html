UtaNote (우타노트)

UtaNote 계정 및 클라우드 데이터 삭제

UtaNote에서 Google 계정을 연결해 클라우드 백업을 사용하셨다면, 언제든지 UtaNote 계정과 그 계정에 연결된 클라우드 데이터를 삭제할 수 있습니다.

앱이 설치되어 있는 경우 (앱에서 바로 삭제)

  1. UtaNote를 실행합니다.
  2. 계정 메뉴를 엽니다.
  3. "계정 및 클라우드 데이터 삭제"를 선택합니다.
  4. 안내 내용을 확인한 뒤 삭제를 진행합니다.
  5. Google 계정으로 본인 확인을 합니다.

앱에서 삭제하면 다음 항목이 삭제됩니다.

  • Firebase Authentication에 있는 UtaNote 계정
  • 클라우드에 저장된 노래 데이터
  • 클라우드에 저장된 폴더 데이터
  • 클라우드에 저장된 폴더-노래 연결 데이터

앱에서 삭제가 정상적으로 끝나면 바로 처리됩니다.

기기에 저장된 노래장은 함께 삭제되지 않습니다.
앱에서 계정을 삭제해도 이 기기 안에 저장된 로컬 노래장 데이터는 그대로 남습니다. 기기에서도 지우려면 Android 설정에서 UtaNote의 앱 데이터를 삭제하거나 앱을 제거하세요.

앱이 없거나 앱을 사용할 수 없는 경우

앱을 다시 설치하지 않아도 됩니다. 아래 버튼으로 이메일을 보내 계정 삭제 요청을 시작할 수 있습니다.

삭제되는 데이터와 남는 데이터

삭제되는 데이터

  • UtaNote Firebase 로그인 계정
  • UtaNote에 연결된 계정 식별 정보
  • 클라우드에 백업된 노래
  • 클라우드에 백업된 폴더
  • 클라우드의 폴더-노래 연결 정보

삭제되지 않는 데이터

  • 사용자의 기기에만 저장된 로컬 노래장 데이터

UtaNote 계정·클라우드 데이터 삭제와 기기 안의 로컬 데이터 삭제는 별개입니다. 계정을 삭제해도 기기 속 노래장은 남아 있고, 기기 속 노래장은 앱 데이터 삭제나 앱 제거로 지울 수 있습니다.

  • 삭제 시각

이 기록에는 이메일, 이름, 노래, 폴더 및 그 밖의 사용자 콘텐츠가 포함되지 않습니다. 이 기록은 삭제된 데이터의 재생성을 방지하기 위한 보안 목적으로 보관합니다.
